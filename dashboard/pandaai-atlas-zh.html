Alpha 研究模块

LLM 引导的蒙特卡洛树搜索

树上的每个节点是一个 Alpha 公式。LLM 提出改进，回测为其打分，搜索再用 UCT 决定下一步改进哪个分支。UCT 在分支的平均得分（利用）和被尝试的稀少程度（探索）之间权衡。调高 c 会更多地探索。

1.40

UCT = Q/N + c·√(ln Nparent / N)

模拟演示。每个分支有一个隐藏的真实质量，每次回测返回该质量加噪声。可以观察到，c 较低时搜索可能锁定在一个早期运气好的分支上。

多样性控制

频繁子树规避（FSA）

如果不加约束，LLM 会反复提出相同的构件。频繁子树规避（出自 Navigating the Alpha Jungle）找出公式库中最常见的根基因，并禁止新提案使用它们。根基因是叶子全部为原始特征的子树，比较时忽略窗口长度等参数。

IC、Rank IC、ICIR 与回撤

Agora：不只进化 Alpha，也进化评分标准

大多数 Alpha 挖掘系统都对着一个固定的评分指标拼命搜索。Agora 的作者认为，正是这种固定评分造成了样本内外表现的落差：搜索学会的是讨好指标，而不是理解市场。Agora 的封闭联合搜索（SJS）让评分函数和因子在“哪个智能体能看到哪些信息”的约束下共同进化。在 Alpha 挖掘智能体搜索的同时，评价挖掘智能体不断修改指标库。点击某个角色，查看它在每一轮中的作用。

    AlphaSchema：先规划交易逻辑，再写代码

    在大多数 LLM 挖掘系统中，智能体既决定尝试什么，也决定怎么写代码，因此探索过程很难引导。AlphaSchema 把两者分开：每个候选先成为一个由五个字段组成的语义方案（schema plan），代理模型给方案打分，搜索每批选出 16 个，然后才由 LLM 把每个方案实现成因子。回测得到的奖励再用来重新训练代理模型。
