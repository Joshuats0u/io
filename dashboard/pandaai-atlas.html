Agora lets agents evolve the scoring metrics along with the alphas. AlphaSchema plans each factor's trading logic before any code is written. LLM-guided Monte Carlo Tree Search

Each tree node is an alpha formula. The LLM proposes refinements, a backtest scores them, and the search uses UCT to decide which branch to refine next. UCT trades off a branch's average score (exploit) against how rarely it has been tried (explore). Raise c to explore more.

Frequent Subtree Avoidance

Left alone, an LLM keeps proposing the same building blocks. Frequent Subtree Avoidance (from Navigating the Alpha Jungle) finds the most common root genes in the formula library and bans them from new proposals. A root gene is a subtree whose leaves are all raw features, compared with window sizes stripped out.

How results are scored

IC, Rank IC, ICIR and drawdown

The paper's claims are in these units. IC is the daily correlation between a factor's values and next-period returns across stocks. Rank IC uses ranks, so a few extreme returns can't dominate it. ICIR is mean IC divided by its standard deviation, a measure of consistency. Drawdown is the worst peak-to-trough fall of the long-short portfolio.

arXiv 2606.29194 · Sealed Joint Search (SJS)

Agora: evolve the scorer, not just the alphas

Most alpha miners search hard against a fixed scoring metric. Agora's authors argue that this fixed scorer causes the gap between in-sample and out-of-sample results: the search learns to please the metric, not the market. Agora's Sealed Joint Search lets scoring functions and factors co-evolve under constraints on which agents can see which information. An evaluation-miner agent keeps changing the metric library while the alpha-miner searches. Select a role to see what it does in each round.

    Toy model on synthetic data. Each alpha has real skill plus an overfit part that only helps in-sample. Search finds overfit gains easier to come by (the overfit pull). The fixed scorer can't tell the two apart. The co-evolving scorer gradually learns metrics that discount the overfit part. In Agora this happens through LLM agents, not a formula.

    AlphaSchema: plan the trade, then write the code

    In most LLM miners, the agent decides both what to try and how to code it, so exploration is hard to steer. AlphaSchema splits the two. Every candidate first becomes a schema plan of five fields. A surrogate model scores plans, the search picks a batch of 16, and only then does an LLM turn each plan into a factor. Backtest rewards retrain the surrogate.
